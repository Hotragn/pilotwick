# Community Companion Gallery 🖼️

Drop your exported `.companion.json` files here via PR to get featured in the
main README Showcase.

**Submission checklist**
- [ ] File is named `<name>-by-<author>.companion.json`
- [ ] `meta.author` is your GitHub handle
- [ ] You own the art or it's licensed for redistribution (say which in `meta.description`)
- [ ] Total file size ≤ 5 MB (compress your GIFs!)
- [ ] Add a row + preview GIF to the README Showcase table

Import any profile from this folder: right-click your companion → Companion
Studio → **Import**.

# docs/assets

Marketing media referenced by the main README.

- `hero.png` — the shot at the top of the README: Companion Studio with the
  pet sitting alongside it. Composed from real screenshots of a release
  build, not a mockup. Regenerate it whenever the Studio changes shape.

## Rules for anything added here

Everything in this folder ships in a public MIT repository, so it must be
**original work or permissively licensed**. No frames from films, games or
anime — however well they fit the mascot. A profile built from someone
else's artwork is still someone else's artwork.

Keep files under ~8 MB so GitHub renders them inline; an animated capture is
welcome as a follow-up to the static hero, but only of the app itself.

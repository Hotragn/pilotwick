Your desktop, quietly aware of what you're doing.

Pilotwick is a small companion that lives on your screen and reacts to your real work — the agent that's thinking, the editor you're in, the build that just went red. It holds your tasks and your focus timer too. Everything runs on your machine.

Download Star on GitHub Windows · macOS · Linux · MIT

What it's actually for

See CI without a tab

Kick off a build and go do something else. When it breaks, the pet turns red, hisses, and keeps a CI chip up until you deal with it.

Know when the agent is done

Stop watching a terminal. Pilotwick reads whichever assistant you use — it isn't tied to one vendor — and celebrates when a long run finishes.

Keep one thing in view

Tasks with real reminders, a Pomodoro timer beside the pet, and an honest breakdown of where the day actually went.

Why it's different

Works with every toolEditors, terminals, browsers, chat, design apps, games and git — not one company's agent.
Local-firstNo account, no telemetry, no backend. Two opt-in features touch the network, both off by default.
Never in the wayClick-through everywhere except the pet itself, and it steps aside for presentations and fullscreen.
Yours to changeAdd an app reaction in one TypeScript file, or upload your own artwork as a shareable profile.

What touches the network

Weather moods (opt-in)Open-Meteo — the city name you typed, nothing else.
Work status (opt-in)GitHub, through your own gh CLI, using credentials you already authorised.

Typing is counted, never recorded — the keyboard hook discards the key code before it reaches the app. Window titles are matched locally and never leave the machine.

What it's actually for

01

See CI without opening a tab

Start a build and go do something else. When it breaks, the companion turns red and keeps a chip up until you deal with it. Reads your own git and gh — nothing is proxied through us.

02

Know when the agent finishes

Stop babysitting a terminal. It reads whichever assistant you use, not one vendor's.

03

Keep one thing in view

Tasks with real reminders, a timer beside the companion, and an honest record of where the day went.

Why it's different

Works with every tool
Editors, terminals, browsers, chat, design apps, games and git. Not one company's agent.
Local-first by construction
No account, no telemetry, no backend. Two opt-in features reach the network, both off by default.
Never in the way
Click-through everywhere except the companion itself, and it steps aside for presentations and fullscreen.
Yours to change
Add an app reaction in one TypeScript file, or import someone else's artwork as a single shareable profile.

What touches the network

Weather moods opt-in
Open-Meteo. The city name you typed, nothing else.
Work status opt-in
GitHub, through your own gh CLI, with credentials you already authorised.
Everything else
Stays here. Typing is counted, never recorded — the keyboard hook discards the key code before it reaches the app.
